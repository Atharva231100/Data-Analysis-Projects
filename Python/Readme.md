# Regional Sales Analysis Using Python & Power BI

## Overview
This project analyzes regional sales data using Python for Exploratory Data Analysis (EDA) and Power BI for interactive dashboard creation. The goal is to uncover sales trends, profitability drivers, and regional performance insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Excel

## Key Analysis
- Data Cleaning & Preprocessing
- Sales Trend Analysis
- Profit Analysis
- Product Performance
- Customer Analysis
- Regional Analysis

## Key Insights
- California generated the highest revenue ($228.8M).
- West region achieved the highest profit margin (37.5%).
- Wholesale was the leading revenue channel.
- Product 26 was the top-performing product.
